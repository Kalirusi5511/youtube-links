🔐 Anmeldung / Admin

Admin‑Login: *Admin‑Authentifizierung erfolgt serverseitig.* Bitte verwende die Server‑API, um dich anzumelden.

Wichtig: Dieser Client akzeptiert **keine** Server‑Secrets oder HMAC_SECRET. Alle Secrets müssen ausschließlich im Render Dashboard als Environment Variables gesetzt werden.

🔑 PIN zurücksetzen

Der Reset‑Workflow erfolgt serverseitig. Du kannst hier einen Recovery‑Code verifizieren oder neue Codes vom Server anfordern.

✅ Einmalige Codes erhalten — bitte sofort sichern. Diese werden nicht im Browser gespeichert.
